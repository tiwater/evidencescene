What is EvidenceScene?

A standalone, modular Python perception & teleoperation library built for real-world contact-rich manipulation

🎯 The Core Challenge in Manipulation Perception

In contact-rich robotic manipulation and bimanual teleoperation, RGB-D sensors routinely encounter severe hand/object occlusions, specular or transparent depth dropouts (often <1% valid depth inside segmentation masks), and asynchronous multi-camera delays.

Existing 6D pose trackers and 3D reconstructors—including CAD foundation models (FoundationPose), online 3D Gaussian Splatting (MonoGS / SplaTAM), feedforward pointmap regressors (MASt3R / CUT3R), static TSDF grids (nvblox), and model-free trackers (BundleTrack / Point2Pose)—either silently hold stale poses, diverge along unobservable depth axes, bake early pose errors irreversibly into static voxels, or suffer from non-deterministic GPU RANSAC race conditions.

🛠️ What EvidenceScene Provides to Research Teams

EvidenceScene is a self-contained, pip-installable Python library (evidencescene) plus audited C++/CUDA patches with zero runtime dependencies on external competitor repositories. Every algorithm is exposed through clean, typed NumPy/SciPy APIs that can be plugged into any RGB-D tracker, SLAM backend, or teleoperation HUD:

• Fail-Closed Factor-Graph Gating (F+G+R+M): Rejects unanchored or rank-deficient pose updates before they corrupt downstream geometry (4.12x lower ADD error under occlusion).
• Columnar Revisable Surfel Memory (S): Retracts and re-fuses per-keyframe surfaces in 1.05 ms when poses are revised, paired with a 0.22 ms 1,500-point budget selector.
• Causal Teleop Safety & O(runs) RLE Algebra: 0.00 mm $C^1$ re-acquisition trajectory blending, 0.81 ms 3D aperture RANSAC, and 5.1x faster RLE interval set operations.

Module I • Deterministic Native Backend

BundleTrack C++/CUDA Determinism & SE(3) Precision

Replaces atomic-order-dependent GPU RANSAC ties with a deterministic stable-winner reduction, selects dense correspondence direction by valid correspondence count rather than raw feature count, repairs single-precision Eigen::Matrix4f::inverse() drift in CUDACache::storeFrame, and retires contiguous NO_BA frames outside the sliding window.

Repeat spread: 0.00 mm / 0.00° • RSS: -928 to -1,994 MiB
Module II • Factor-Graph Observability

Causal Factor-Graph Gating (F + G + R + M + S)

Prevents floating gauge components and rank-deficient 3D point-to-point admissions by enforcing prior-connected anchor admission (G) and Schur-complement marginal translational observability rank gating (R) before committing poses or surface surfels.

R_i = J_{ii}^T J_{ii} - J_{iL}^T (J_{LL})^† J_{Li}, σ_min(R_i) ≥ τ_rank
Module III • Revisable Surface Memory

Columnar RevisableSurfelMap & 1,500-Point Selector

Couples a feature-birth observation ledger (M) and sorted Structure-of-Arrays (SoA) surface-history rebuild transactions (S) with an array-native support10/coarse12mm two-stage surfel selector that prioritizes multi-view corroborated surfels (c_s ≥ 10) in 0.22 ms (93.0x speedup).

C_10: 40.57% → 85.10% (YCB) • Snapshot: 20.48 → 0.22 ms (93.0x)
Module IV • Zero-Loss Runtime

GPU-Window CPU Overlap & O(runs) RLE Arithmetic

Executes deterministic CPU preparation concurrently inside the SAM2 GPU inference window (SAM2GpuWindowOverlapScope), computes mask bounding boxes, areas, centroids, and pairwise IoU directly on integer RLE run intervals in O(R) time, and vectorizes coplanar AprilTag RANSAC SVD.

p50/p95: 127.80 / 153.40 ms • 499/499 Bit-Exact Parity

Academic Paper Abstract

Standard 6D object pose and 3D surface reconstruction benchmarks frequently conflate offline batch optimization, unverified last-pose hold heuristics, and non-deterministic GPU correspondence reductions with genuine online tracking observability. When deployed in contact-rich robotic manipulation and teleoperation, silent pose holds and unconditioned factor-graph admissions produce ghost surface artifacts, unbounded memory growth, and uncalibrated trajectory jumps.

We introduce EvidenceScene, an evidence-constrained, observability-conditioned 3D scene reconstruction framework that tracks 6D object pose and maintains a revisable surface representation, combining a deterministic native BundleTrack backend with causal factor-graph observability gating and lineage-indexed surface reconstruction. First, we diagnose and eliminate native C++/CUDA non-determinism in BundleTrack via a deterministic stable-winner RANSAC reduction, correspondence-count direction selection, and full-precision SE(3) inverse caching in CUDACache::storeFrame, driving repeated-execution pose spread to 0.00 mm / 0.00° while increasing strict motion-capture successes on Laval Vicon Clock/Jar from 135/107 to 191/136 and cutting peak process RSS by up to 1,994.0 MiB via guarded contiguous-NO_BA frame retirement.

Second, we formalize a five-stage causal factor-graph observability and surface lineage stack (F + G + R + M + S) for point-track pose graphs: solver correctness fixes (F), prior-connected keyframe admission (G), Schur-complement marginal translational rank gating (R), feature-birth observation ledgers (M), and causal surface-history rebuild transactions (S) paired with a sorted columnar Structure-of-Arrays (SoA) RevisableSurfelMap support10/coarse12mm 1,500-point selector that cuts 60k-point snapshot latency from 20.48 ms to 0.22 ms (93.0x speedup, 8.65x geomean across all 7 kernels) and raises 10-view surface corroboration (C₁₀) from 40.57%/52.34% to 85.10%/85.05%. Finally, we introduce zero-loss concurrent GPU-window CPU overlap (SAM2GpuWindowOverlapScope) and O(runs) integer RLE mask interval arithmetic (RequestEvidenceDeduplicationScope), reducing warm end-to-end p50/p95 latency from 155.33/219.06 ms to 127.80/153.40 ms with 100% bit-exact output parity.
