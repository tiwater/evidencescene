Project Overview

Why existing 6-DoF trackers and voxel maps fail in manipulation—and how EvidenceScene solves it

In contact-rich robotic manipulation (grasping, pouring, bimanual handovers), hands frequently occlude the manipulated object and transparent or specular surfaces return fewer than 1% valid depth pixels. Existing model-free trackers (such as Point2Pose and unmodified BundleTrack) either lose tracking, commit rank-deficient pose updates that jump by 70–330 mm, or suffer from GPU atomic RANSAC non-determinism and single-precision SE(3) drift. Meanwhile, static voxel grids (such as TSDF / nvblox) permanently bake early noisy keyframes into ghost double-wall surfaces.

EvidenceScene solves both problems jointly: (1) we make native C++/CUDA correspondence and pose optimization 100% deterministic (0.00 mm / 0.00° repeat spread) with full-precision SE(3) caching and contiguous frame retirement (-1.99 GiB peak RSS); (2) we gate every pose update on Schur-complement marginal translational observability so occluded frames cannot corrupt the trajectory; and (3) we replace static voxel fusion with a columnar Structure-of-Arrays RevisableSurfelMap that retroactively updates historical surface geometry in 0.14 ms whenever keyframe poses are refined.

Framework Overview

Causal observability gating coupled with keyframe-indexed 3D surface revision

Given multi-camera or monocular RGB-D frames and instance masks, EvidenceScene processes observations through four tightly coupled stages: (1) Deterministic Native Backend replaces atomic GPU RANSAC tie races with a deterministic stable-winner reduction and full-precision SE(3) inverse caching in CUDACache::storeFrame; (2) Causal Observability Gate (F + G + R) computes the Schur-complement marginal translational information matrix R_i = J_{ii}^T J_{ii} - J_{iL}^T (J_{LL})^† J_{Li} and blocks rank-deficient pose jumps before they corrupt the trajectory; (3) Columnar RevisableSurfelMap (M + S) indexes surfels by originating keyframe in Structure-of-Arrays columns so historical surface geometry can be revised in 0.14 ms and down-selected to 1,500 corroborated surfels in 0.22 ms (93.0× speedup); and (4) Zero-Loss Runtime Overlap overlaps CPU preparation inside the SAM2 GPU window and executes mask algebra directly on integer RLE runs in O(runs) time.
