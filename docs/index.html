1. What is EvidenceScene?

Overview of the research problem, technical approach, and Python library structure

Overview. EvidenceScene is an open-source Python library and a companion set of audited C++/CUDA patches for tracking 6-DoF object poses and maintaining revisable 3D object surfaces from RGB-D streams during robotic manipulation and teleoperation. The Python package depends only on NumPy and SciPy, contains no runtime dependencies on external competitor repositories, and can be integrated modularly into existing perception or teleoperation pipelines.

Problem Statement. In contact-rich manipulation tasks (such as grasping, container pouring, and bimanual handovers), objects are frequently occluded by robot fingers or containers, and specular or transparent surfaces often yield sparse depth measurements (under 1% valid depth pixels inside a 2D segmentation mask). Under these conditions, correspondence-based and factor-graph trackers can become rank-deficient along specific translational or rotational directions. When unobservable pose updates are silently committed—or when early noisy observations are permanently fused into a static voxel grid—errors accumulate as ghost surface layers and uncalibrated pose jumps.

Technical Approach. EvidenceScene addresses these failure modes through four components: (i) deterministic C++/CUDA patches to BundleTrack that eliminate GPU RANSAC tie-breaking race conditions and single-precision SE(3) drift while bounding memory via contiguous-NO_BA frame retirement; (ii) causal factor-graph observability gating (F + G + R + M) that verifies prior-connected graph reachability and Schur-complement marginal translational rank before committing pose updates; (iii) a keyframe-indexed, Structure-of-Arrays (SoA) RevisableSurfelMap (S) that retracts and re-fuses per-keyframe surface observations in 1.05 ms when historical poses are revised, paired with a 0.22 ms two-stage 1,500-point selector (support10/coarse12mm); and (iv) exact O(runs) run-length-encoded (RLE) mask interval algebra and causal C¹ SE(3) trajectory prediction for teleoperation clearance verification.

3.1 Deterministic Native BundleTrack Backend & Memory Retirement

Upstream BundleTrack exhibits run-to-run variation due to atomic race conditions in GPU RANSAC hypothesis reduction, selects correspondence direction by raw feature count rather than valid correspondence count, and accumulates single-precision Eigen::Matrix4f::inverse() drift in CUDACache::storeFrame. Our patches replace atomic ties with a deterministic stable-winner reduction, select correspondence direction by valid inlier count, compute full-precision SE(3) inverses, and retire contiguous NO_BA frames outside the active window.

Repeated-execution spread: 0.00 mm / 0.00° • Peak RSS reduction: 928.4 to 1,994.0 MiB

3.2 Causal Factor-Graph Observability Gating (F + G + R + M)

In point-track pose graphs, a frame observing fewer than three non-collinear 3D landmarks—or disconnected from any prior-anchored keyframe—is rank-deficient. Before admitting a keyframe or committing its pose to the surface map, FactorGraphObservabilityLedger verifies prior-connected reachability (G) and evaluates the Schur-complement marginal translational information matrix (R) after eliminating landmark blocks.

R_i = J_{ii}^T J_{ii} - J_{iL}^T (J_{LL})^† J_{Li}, admit iff σ_min(R_i) ≥ τ_rank

3.3 Columnar RevisableSurfelMap & Two-Stage 1,500-Point Selector (S)

Unlike static TSDF grids that irreversibly average early noisy poses into voxel weights, RevisableSurfelMap stores per-keyframe quantized observations in sorted Structure-of-Arrays (SoA) columns. When a keyframe pose is revised or retracted, its historical contribution is updated in 1.05 ms (69.8x faster than dictionary storage). A two-stage support10/coarse12mm selector extracts a 1,500-point wire snapshot in 0.22 ms (93.0x faster), prioritizing surfels corroborated across at least 10 views while preserving spatial coverage on a 12 mm coarse lattice.

10-view corroboration C₁₀: 40.57% → 85.10% (YCB) • 60k-point snapshot latency: 20.48 ms → 0.22 ms

3.4 O(runs) RLE Mask Algebra & GPU-Window CPU Overlap

SAM2GpuWindowOverlapScope overlaps deterministic CPU frame preparation with the GPU segmentation inference window, while RequestEvidenceDeduplicationScope computes mask unions, intersections, IoU, bounding boxes, and centroids directly on 1D run-length intervals in O(R) time and vectorizes 240-hypothesis AprilTag coplanar RANSAC SVD.

Warm 4-camera endpoint latency (p50 / p95): 155.33 / 219.06 ms → 127.80 / 153.40 ms (499 / 499 bit-exact parity)

Paper Abstract

Standard 6D object pose and 3D surface reconstruction benchmarks frequently conflate offline batch optimization, unverified last-pose hold heuristics, and non-deterministic GPU correspondence reductions with genuine online tracking observability. When deployed in contact-rich robotic manipulation and teleoperation, silent pose holds and unconditioned factor-graph admissions produce ghost surface artifacts, unbounded memory growth, and uncalibrated trajectory jumps.

We introduce EvidenceScene, an evidence-constrained, observability-conditioned 3D scene reconstruction framework that tracks 6D object pose and maintains a revisable surface representation, combining a deterministic native BundleTrack backend with causal factor-graph observability gating and lineage-indexed surface reconstruction. First, we diagnose and eliminate native C++/CUDA non-determinism in BundleTrack via a deterministic stable-winner RANSAC reduction, correspondence-count direction selection, and full-precision SE(3) inverse caching in CUDACache::storeFrame, driving repeated-execution pose spread to 0.00 mm / 0.00° while increasing strict motion-capture successes on Laval Vicon Clock/Jar from 135/107 to 191/136 and cutting peak process RSS by up to 1,994.0 MiB via guarded contiguous-NO_BA frame retirement.

Second, we formalize a five-stage causal factor-graph observability and surface lineage stack (F + G + R + M + S) for point-track pose graphs: solver correctness fixes (F), prior-connected keyframe admission (G), Schur-complement marginal translational rank gating (R), feature-birth observation ledgers (M), and causal surface-history rebuild transactions (S) paired with a sorted columnar Structure-of-Arrays (SoA) RevisableSurfelMap support10/coarse12mm 1,500-point selector that cuts 60k-point snapshot latency from 20.48 ms to 0.22 ms (93.0x speedup, 8.65x geomean across all 7 kernels) and raises 10-view surface corroboration (C₁₀) from 40.57%/52.34% to 85.10%/85.05%. Finally, we introduce zero-loss concurrent GPU-window CPU overlap (SAM2GpuWindowOverlapScope) and O(runs) integer RLE mask interval arithmetic (RequestEvidenceDeduplicationScope), reducing warm end-to-end p50/p95 latency from 155.33/219.06 ms to 127.80/153.40 ms with 100% bit-exact output parity.
